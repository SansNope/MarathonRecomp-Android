# Official APK signing

The v0.1.0 release uses a dedicated RSA-4096 signing key. Public certificate SHA-256:

```text
6c1d648d9be4db74761fe5fe5cf5c49482c7dcc84554750810c1bf0c03806ea3
```

`release-certificate.pem` and `release.lineage` are public verification material. The signing key and its backups are maintained outside the repository.

The lineage links the maintainer's earlier development certificate
`a7856dc08093f92e9187d0d3bcb88e8cdfc1d104ff137a42e9855b897fa70eb0`
to the release certificate, with the installed-data capability enabled. APK signing uses the rotated key from API28; the app's minimum is API29. This preserves the cryptographic update path from the maintainer's tested development APKs. Installation of the newly packaged release is a separate device check.

For future official releases, preserve the same signing key and lineage. A fresh key generated by another developer will not produce an official update. See [Android signing](https://developer.android.com/studio/publish/app-signing) and [apksigner rotation](https://developer.android.com/tools/apksigner).

## Private signing configuration

Create a JSON file outside the checkout, then pass its path with `-SigningConfig` or `MARATHON_RELEASE_SIGNING_CONFIG`. Password files contain one password line each. Use different files for the store and key passwords, even when the values are the same. Keep the files and keystore backed up and accessible only to their owner.

For your own independent build:

```json
{
  "signers": [
    {
      "keystore": "C:/private/my-release.p12",
      "alias": "my-release",
      "storePasswordFile": "C:/private/store-password.txt",
      "keyPasswordFile": "C:/private/key-password.txt"
    }
  ]
}
```

For an official rotated build, the private configuration additionally specifies `lineageFile` and both signers, oldest first. `Sign-Apk.ps1` aligns the unsigned APK, signs it with apksigner, checks the signature for API29+, and checks alignment. Passwords are passed as file references, not as literal command arguments. The repository does not contain the private configuration.

```powershell
.\android\scripts\Build-Apk.ps1 -Variant Release -ArtifactName MarathonRecomp-Android-v0.1.0-arm64-v8a -SigningConfig C:\private\signing.json
```
