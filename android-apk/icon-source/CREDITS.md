# App icon

`sonic06-icon-gsnreboot.jpg` (768×768, SHA-256 `b273fc8ebeee29b443e385f5eaa36886556356345f05e418420c54c5c6dc8c0d`) — artwork by **GSNReboot**, taken from
GameBanana. Provided by the project owner (SansNope) on 26.10.2026 for use as the launcher icon.
Credited in the launcher's Info window (`launcher_info_text` in res/values*/strings.xml).

Generated from it (scratch script, Pillow, Lanczos):
- `res/mipmap-*/ic_launcher.png` — 48dp legacy icon, the whole image;
- `res/mipmap-*/ic_launcher_background.png` — 108dp adaptive background layer, image scaled to
  90dp in the centre and edge pixels extended, so the 72dp visible area shows ~80% of the art;
- `res/mipmap-anydpi-v26/ic_launcher.xml` — adaptive icon using that layer.
