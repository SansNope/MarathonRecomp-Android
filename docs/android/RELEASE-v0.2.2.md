# MarathonRecomp-Android v0.2.2

**Fixes from the original MarathonRecomp.** ARM64, Android 10 (API 29) or newer, Vulkan. Installs over v0.2.1 and keeps your saves.

## Changes

These fixes were **ported unchanged from the original [MarathonRecomp](https://github.com/sonicnext-dev/MarathonRecomp) repository** by the MarathonRecomp team; all credit goes to them:

- **[#323](https://github.com/sonicnext-dev/MarathonRecomp/pull/323)** — the mission window no longer closes the talk window when a mission has no mission text.
- **[#330](https://github.com/sonicnext-dev/MarathonRecomp/pull/330)** — the title screen video now follows the in-game music volume.
- **[#316](https://github.com/sonicnext-dev/MarathonRecomp/pull/316)** — the duplicate button guide on the main menu is hidden.
- **[#327](https://github.com/sonicnext-dev/MarathonRecomp/pull/327)** — in multiplayer, every player owns the same downloadable content (before, only the first player did).

The camera fix [#317](https://github.com/sonicnext-dev/MarathonRecomp/pull/317) (gamepad and touch stick camera getting stuck) has been included since v0.2.0.

Version 0.2.2 (code 8), same signing key.

## Tested

- **POCO F5** (Adreno 725): the 0.2.2 test build starts and plays without errors. The visible effect of each fix was not checked one by one.

## Known issues

Unchanged from [v0.2.1](https://github.com/SansNope/MarathonRecomp-Android/blob/main/docs/android/RELEASE-v0.2.1.md#known-issues): loading screens and videos flicker on a Helio G99 phone, and everything listed for [v0.2.0](https://github.com/SansNope/MarathonRecomp-Android/blob/main/docs/android/RELEASE-v0.2.0.md#known-issues).

## Русский

**Исправления из оригинального MarathonRecomp.** ARM64, Android 10 (API 29) и новее, Vulkan. Ставится поверх v0.2.1 с сохранением данных.

### Изменения

Эти исправления **перенесены без изменений из оригинального репозитория [MarathonRecomp](https://github.com/sonicnext-dev/MarathonRecomp)**; их авторы — команда MarathonRecomp:

- **[#323](https://github.com/sonicnext-dev/MarathonRecomp/pull/323)** — окно миссии больше не закрывает окно диалога, если у миссии нет текста.
- **[#330](https://github.com/sonicnext-dev/MarathonRecomp/pull/330)** — громкость ролика на титульном экране теперь следует громкости музыки в игре.
- **[#316](https://github.com/sonicnext-dev/MarathonRecomp/pull/316)** — скрыта дублирующая подсказка кнопок в главном меню.
- **[#327](https://github.com/sonicnext-dev/MarathonRecomp/pull/327)** — в мультиплеере загружаемый контент доступен всем игрокам (раньше — только первому).

Исправление камеры [#317](https://github.com/sonicnext-dev/MarathonRecomp/pull/317) (камера переставала слушаться стика геймпада и сенсорного стика) входит в порт с v0.2.0.

Версия 0.2.2 (код 8), тот же ключ подписи.

### Проверено

- **POCO F5** (Adreno 725): тестовая сборка 0.2.2 запускается и играется без ошибок. Видимый результат каждого исправления по отдельности не проверялся.

### Известные проблемы

Без изменений с [v0.2.1](https://github.com/SansNope/MarathonRecomp-Android/blob/main/docs/android/RELEASE-v0.2.1.md#known-issues): мерцание загрузочных экранов и роликов на телефоне с Helio G99, а также всё, что перечислено для [v0.2.0](https://github.com/SansNope/MarathonRecomp-Android/blob/main/docs/android/RELEASE-v0.2.0.md#known-issues).
